# GenBankViz documentation

GenBankViz is a focused, local-first browser viewer for GenBank genomes. The [live application](https://linsalrob.github.io/GenBankViz/) loads local plain or gzip-compressed records, displays grouped annotations and six reading frames, and performs exact nucleotide or peptide searches without uploading sequence data.

New users should start with [How to use GenBankViz](how-to-use-GenBankViz.md), [Loading files](loading-files.md), and [Navigating and zooming](navigation.md). The reference section documents [GenBank support](genbank-support.md), [feature keys and display groups](feature-groups.md), [qualifiers](qualifiers.md), [genetic codes](genetic-codes.md), and exact [search semantics](search-semantics.md).

For use without an internet connection, begin with [Standalone and offline installation](offline-installation.md). The current offline option is a local production build, not an installer or PWA. See [privacy and security](privacy-and-security.md) before handling sensitive data.

Developers can read [installation](installation.md), [architecture](architecture.md), [coordinates](coordinate-system.md), [testing and fixtures](testing.md), [documentation maintenance](documentation.md), and [Read the Docs integration](readthedocs.md).
